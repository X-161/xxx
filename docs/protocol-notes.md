# 串口协议设计笔记

## 先回答的问题

1. 设备发送的是文本还是二进制数据？
2. 一条数据怎样开始、怎样结束？
3. 如何判断一条数据是否完整？
4. 数据损坏时如何发现？
5. 各字段的单位和有效范围是什么？

## 第一版练习协议

建议先使用容易观察的文本协议：

```text
TYPE,VALUE\n
```

示例：

```text
TEMP,25.6
LIGHT,318
```

待补充：

- [ ] 支持哪些 `TYPE`
- [ ] 每个值的单位
- [ ] 合理取值范围
- [ ] 是否需要设备编号
- [ ] 是否需要校验和
- [ ] 遇到乱码或缺字段时的处理策略
