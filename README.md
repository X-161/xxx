# Python 串口数据采集学习项目

这是一个面向信息工程专业学生的渐进式练习项目。目标是从串口通信基础出发，逐步完成数据接收、解析、保存与可视化。

> 当前阶段只搭建项目骨架和学习路线，不包含完整的数据采集实现。

## 学习目标

完成本项目后，你应当能够：

- 解释波特率、数据位、停止位、校验位和串口号的含义
- 使用 Python 打开和关闭串口
- 设计简单、可验证的数据帧格式
- 将串口字节流解析为结构化数据
- 保存 CSV 数据并绘制实时波形
- 编写基础测试、记录异常并使用 Git 管理改动

## 环境准备

建议使用 Python 3.10 或更高版本。

```bash
python -m venv .venv
```

Windows PowerShell：

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 推荐的学习方式

1. 先阅读 [学习计划](LEARNING_PLAN.md) 的当前阶段。
2. 自己完成一个小 TODO，不要一次实现所有功能。
3. 使用虚拟串口或简单设备验证结果。
4. 为每次实验记录输入、输出、错误和结论。
5. 每完成一个小功能就提交一次 Git commit。

## 第一项任务

先不要连接真实硬件。完成以下准备：

- [ ] 阅读 `docs/protocol-notes.md`
- [ ] 了解电脑上的串口号如何查看
- [ ] 写出一份示例数据帧，如 `TEMP,25.6\n`
- [ ] 在纸上说明程序从“接收字节”到“保存数据”的流程
- [ ] 为 `main.py` 的命令行参数写出设计草稿
